Behind the puzzle

How it works

There’s no JavaScript on this site, so the crossword is built from HTML forms and CSS.

  • Each square is a text input with maxlength="1", laid out with CSS Grid.
  • The word you’re in and its clue are highlighted with :has() and :focus.
  • Each input has a pattern for its letter, so form:valid tells the page when the whole grid is right.
